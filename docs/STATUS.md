The initial macOS foundation is Munim Computer Use at `883a4e181409f203b4b51f8219d88e0af43b1034` plus `patches/munim-secure-subrole.patch`; see ADR-001 for the actual comparison. The stdio server starts a Munim child and exposes `computer` and `desktop`. It lists apps (window listing is not implemented); inspects non-protected app bundle IDs (the local policy now enables all non-protected apps); and requests a single-use, expiring confirmation for a small allowlist of Calculator buttons or up to 200 printable characters inserted or replaced in a TextEdit text area in the current snapshot. Replacement has only been tested with a simulated backend. Other input is blocked. Optional `query` and `window` inspection arguments narrow the result. It suppresses complete text responses when known secure-field markers are detected and records minimal request audit metadata without typed text. A panic-stop file refuses requests, and each server process limits requests to 120 per minute; the limit is not shared across processes. `policy.yaml` supports normal, read-only and dry-run modes and confirmation expiry. Unsupported policy fields are rejected. A cooperative lock and shared generation coordinate handsmcp processes, but not external desktop activity or other automation tools. It re-reads and compares snapshots immediately before input, but this is not an atomic identity check and cannot eliminate races with external activity. Agent instructions require explicit human approval; the server cannot force an agent to ask.
