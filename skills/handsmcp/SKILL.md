# handsmcp (experimental)

Inspect first using the read-only `inspect_app` tool with a permitted exact bundle ID and optional `window` and `query`. `computer` action `inspect` remains available for older clients. Refs are snapshot-scoped. `desktop` `list_applications` returns allowed running apps. Use `desktop` action `launch_application` with an exact allowed bundle ID when an app is not running; inspect afterward to verify it opened. Click a named Button with `computer` action `click` and `ref`; insert up to 200 printable characters or replace up to 2000 characters into a verified TextArea, TextField, or SearchField with `computer` action `type`, `ref`, `text`, and `mode=replace` for replacement. TextEdit supports newline and tab in the text. These actions require confirmation. When the server returns `confirmation_required`, show the user the exact summary and wait for explicit approval before using the token; never confirm on your own. Verify the result by inspecting again. Do not enter passwords, tokens, verification codes or other secrets.

Do not bypass limitations by calling the underlying runtime. Known secure fields and unknown fields are blocked, but marker and app-name filtering is incomplete. After an unfiltered inspection, `computer` action `press_key` supports navigation keys and Command/Control shortcuts via `{"key":"s","modifiers":["cmd"]}`; these require confirmation. Literal characters and clipboard paste are blocked by this route. After an unfiltered inspection, `computer` action `scroll` accepts `{"direction":"down","amount":4}` and requires confirmation. Verify that the view actually moved. After a complete, unfiltered inspection of all app windows, visual fallback can request `desktop` action `visual_click` with `{"x":120,"y":200}` in global screen points from the screenshot metadata. The action requires confirmation and the snapshot must remain unchanged; inspect afterward to verify the result. Protected or unverified fields and incomplete trees block this fallback. Other roles and general interactions remain incomplete. The input implementation is experimental and has not been broadly verified live.

The `screenshot` tool can request an image of the largest window of an allowed app by exact bundle ID. It checks all app windows and refuses known secure or unverified fields and incomplete trees; check metadata to identify which window was captured; it refreshes refs, so inspect again after use. macOS Screen Recording permission is required. Antigravity successfully captured a temporary test window; capture from other launchers may have different macOS permissions.
